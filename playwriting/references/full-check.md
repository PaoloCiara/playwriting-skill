# Full check

For "check over everything", and before any draft is delivered. Work down the list. Write each finding with the line it comes from. Fix what's clear, ask about what's a choice, and leave alone what works.

Use only files the writer pointed to. A matching title isn't permission: if a play or note can't be found, say so and ask.

1. **The writer's notes.** Read `writer-voice.md` top to bottom. Test the draft against every note, not only the newest one. Fixing one often breaks another (quick became choppy, plain became flat).
2. **What's protected.** Search for each accepted or protected line word for word.
3. **The book.** Run `guidebook-checks.md`. At least: want and obstacle in each scene, one event per scene and whose mind changes, why today, nobody trying to leave, the ending no bigger than it needs to be.
4. **The plays.** Compare rhythm and directions with `from-plays.md` and with the writer's own draft (`read_play.py` prints turn length, sentence length, directions per spoken word). Read the shortest-lined scene aloud.
5. **The room.** Run it with no crew, on the set they have. List every prop and garment, where it starts and ends, who moves it, how many seconds the actor has. Check that a glass said to be half empty is half empty.
6. **Time and facts.** Put every date, age and length of time in one line and add them up. Check nobody quotes a line that was never said, and nothing is remembered before it happens.
7. **Character page.** Each description is a sentence or two of traits (Spencer 137, exercise 156). Then find the lines that prove each trait. No line, change the trait. Strong lines with no trait behind them, add it. Update the page whenever the scenes have changed the people.
8. **Setting and time.** Read them aloud. They should sound like someone describing the play, not a schedule or an equipment list. See `manuscript-format.md`.
9. **Too neat, again.** Count echoes and returning objects. Cut the cleverest.
10. **Report.** What was checked, what was wrong, what changed, what's invented, what couldn't be checked or used.
