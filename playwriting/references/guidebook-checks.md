# Guidebook checks

Stuart Spencer, *The Playwright's Guidebook*. A map to the book, not a substitute: the writer needs their own copy, and the pages are worth reading for the job at hand. Page numbers come from one PDF and may be off in other editions, so check the topic. The questions are this skill's own wording.

```bash
osascript -l JavaScript <skill>/scripts/read_book.js "<the pdf>" <scratch>/book.txt 144 156
```

Two things outrank a check: the writer's own notes and formatting, and Spencer's first rule of rewriting (171–172): if a passage works, leave it alone.
