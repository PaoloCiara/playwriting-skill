# Starting, and getting unstuck

## Starting from nothing
Begin with an image rather than a theme: two people, one place, an hour, the light, a smell, an object. Make it specific until it feels remembered. Write fast for an hour without planning. Then look for the want, obstacle and change already hiding in it, and support those. If the writer arrives with a theme, turn it into such an image first.

Overwrite the first draft. A thin play can't be fixed by cutting.

## Moves when a scene won't come
| Move | How |
|---|---|
| Occasion | Set it on a day with something else going on: a wedding, a move, a last lunch |
| Object | Replace the abstract want with a thing |
| Start later | Begin once someone is already pursuing something, already at a simmer |
| Lock the door | Make both people need to stay |
| Swap | Trade the two characters' positions, or reverse a want |
| Clock | Fix the exact time since the last scene and what it did to them |
| Recentre | Ask whether the play belongs to someone else |
| Prose it | Tell the plot in a page of plain prose before writing scenes |
| Jump | Skip the explanation and trust the audience to have followed |
| Fresh line | Delete the bad line and write a new one; park cuts in a Cuts file |
| Quiet ending | The end needs to be caused, not loud |

Be wary of illness, madness, accident or coincidence doing the plot's work.
